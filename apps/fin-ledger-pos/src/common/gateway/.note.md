| Feature                      | GatewayService (Hosted Invoice)                 | CheckoutService (Direct Payment Request API)                                                 |
| ---------------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **Xendit API Endpoint Used** | `/v2/invoices`                                  | `/v2/payment_requests` & `/v2/payment_methods`                                               |
| **User Experience**          | Redirects user to a Xendit-hosted webpage.      | Keeps user inside your app/POS. Returns raw QR code strings or VA numbers.                   |
| **Payment Selection**        | Customer picks payment method on Xendit's page. | Customer picks method in your UI, which tells backend explicitly (e.g., `SHOPEEPAY`, `BCA`). |
| **Code Duplication**         | Low (Xendit manages VA/QR/E-Wallet logic).      | High (requires `switch(payment.type)` for each method).                                      |
| **Best Used For**            | Web e-commerce checkouts.                       | Point-Of-Sale (POS) apps, mobile apps, or custom checkout flows.                             |
