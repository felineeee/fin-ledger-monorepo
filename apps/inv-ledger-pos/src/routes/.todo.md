### Route: `[METHOD] /api/v1/path`

#### 1. Request Validation

- [ ] DTO class defined for Body / Params / Query with `class-validator` decorators.
- [ ] DTO bound using `@Body()`, `@Param()`, or `@Query()`.
- [ ] Route parameters validated via explicit pipes (e.g., `ParseUUIDPipe`).

#### 2. Authentication & Authorization

- [ ] Protected by global or route-level JWT auth guard (unless intentionally public).
- [ ] RBAC guard applied (e.g., `@Roles()` decorator + `RolesGuard`).
- [ ] **IDOR Prevention:** Service layer verifies the resource belongs to the user's location/branch scope.
- [ ] Consistent IDOR Policy: Standardized on returning `404 Not Found` vs `403 Forbidden` for unauthorized resource access.

#### 3. Response Contracts & Serialization

- [ ] Correct HTTP Status Code returned (`200` OK, `201` Created, `204` No Content).
- [ ] Response DTO applied using `class-transformer` (`@Exclude()` on internal fields).
- [ ] Output follows standard envelope shape (`{ data, meta }` for lists, `{ data }` for single resources).

#### 4. Error Handling & Mapping

- [ ] Failures throw NestJS HTTP Exceptions (`NotFoundException`, `ConflictException`, etc.).
- [ ] Kysely database errors (foreign key constraint, unique violation) caught and converted to HTTP status codes.
- [ ] Global exception filter prevents raw SQL / stack trace exposure.

#### 5. Kysely Data Layer

- [ ] Multi-step writes are wrapped in a Kysely transaction (`db.transaction().execute(...)`).
- [ ] Row-level locking (`FOR UPDATE`) applied on concurrent state shifts (inventory decrements, transfers).
- [ ] Query performance checked to prevent N+1 relational fetches.

#### 6. Pagination (List Endpoints Only)

- [ ] `limit` and `offset`/`cursor` query params enforced with a hard maximum cap.
- [ ] Response includes total counts/pagination metadata (`totalItems`, `totalPages`, `hasNextPage`).

#### 7. Swagger Documentation

- [ ] Route decorated with `@ApiTags()`, `@ApiOperation()`, and `@ApiBearerAuth()`.
- [ ] All status code outcomes explicitly documented using `@ApiResponse()`.
- [ ] DTO fields documented with `@ApiProperty()`.

#### 8. Observability & Reliability

- [ ] Structural log written on failure containing context (`userId`, `resourceId`) without PII/credentials.
- [ ] Request/Correlation ID passed through for cross-service tracing.
- [ ] **Idempotency:** Implemented idempotency key check if this route handles retriable writes (payments, receiving, scans).

#### 9. Testing & Quality Assurance

- [ ] Service unit tests written using mock Kysely instances.
- [ ] Integration/E2E test covering Happy Path + Failure Path.
- [ ] Dedicated test verifying IDOR prevention (Location A user accessing Location B resource).
