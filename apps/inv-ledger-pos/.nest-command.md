## NestJS CLI Quick Reference

### Core Generation Commands

| Resource          | Short Command       | Full Command               | Description                                                 |
| ----------------- | ------------------- | -------------------------- | ----------------------------------------------------------- |
| **Module**        | `nest g mo <name>`  | `nest g module <name>`     | Defines feature boundary and dependency injection context   |
| **Service**       | `nest g s <name>`   | `nest g service <name>`    | Handles business logic and database interactions            |
| **Controller**    | `nest g co <name>`  | `nest g controller <name>` | Handles incoming REST routes and HTTP requests              |
| **Full Resource** | `nest g res <name>` | `nest g resource <name>`   | Generates Module, Service, Controller, and DTOs all at once |

---

### Useful CLI Flags

#### 1. Dry Run (`--dry-run` or `-d`)

Previews file generation and updates without modifying your filesystem:

```bash
nest g s locations --dry-run

```

#### 2. Skip Spec Files (`--no-spec`)

Generates implementation files without accompanying unit test (`.spec.ts`) files:

```bash
nest g co locations --no-spec

```

---

> **Pro Tip:** You can chain flags together for faster scaffolding:
>
> ```bash
> nest g res inventory --no-spec --dry-run
>
> ```
